# Source code and measurement audit

All additions are post hoc. Neither original model inputs nor any main/supplemental fitted-model metric were changed. The 53-company, 120-observation selection and exact original accession rule remain fixed.

## Source implementation inspected

The paper-linked companion repository is WaguyMz/Financial-Statements-Fraud-Detection, pinned at commit 8c292f2af557f4153f4f605668756c9ce5a4c870. Four inspected files match the corresponding Git blobs in its parent repository at b4cc1a46cc829f96c489628c9985f88806958a7e. Git blob identities were verified from exact UTF-8 bytes. Manifest records include source URL, byte count, Git object SHA1 and SHA256. No repository license was detected; complete source files are retained in the local working cache and are not redistributed. A linked repository and a plausible code path do not certify that the pinned Hugging Face data were generated by that exact commit.

The financial preprocessing file contains these inspectable choices:

- Lines 604-613 restrict numeric records to qtrs 0 or 1 and retain the latest ddate within accession/tag. No equality condition between ddate and submission period is applied there. Unit/context filtering and tag joins elsewhere also affect results.
- Lines 531-545 return zero for division with a zero/missing denominator or missing numerator, return zero when any summed component is zero/missing, and default absent tags to zero. These are coded conventions, not a claim that every released zero is erroneous.
- Lines 1039-1079 remove zero values from inputs to taxonomy inference, fill absent resulting tags with zero, and also fill input missing values with zero.
- Lines 1284-1563 implement the twelve modeled formulas; the formula dictionary records individual locators. Profit margins use the literal Revenues tag; cash ratios use CashCashEquivalentsAndShortTermInvestments.

## Executed scope and access limits

The official 2020 Q4 bulk archive download returned HTTP 403. No alternate restricted route or access bypass was attempted. The full original NUM/PRE/TAG/SUB snapshot and taxonomy environment were not reconstructed. The inspected repository also does not supply all imported configuration/taxonomy modules needed for a full run.

replay_upstream_helpers.py loads only the three specified function definitions and the exact latest-date selector statement via Python's abstract syntax tree. No original top-level source commands or network calls are executed. The exact helper file hash is required. The supplied source manifest allows retrieval of that public file separately.

On observed USD instant facts in Sensus accession 0001213900-20-036128, the actual source selector retains HeldToMaturitySecuritiesCurrent of USD 7,389,407 dated December 31, 2019, for the report whose current end is September 30, 2020. These are actual API facts, not fabricated observations, but companyfacts is not identical to the original NUM/PRE/TAG tables. This proves what the isolated selector does on that observed input; it does not fully reproduce the original extraction or taxonomy aggregation that produced the distributed cash ratio. The exact current-cash-plus-prior-investment fingerprint from Revision 3 is preserved with this stronger but still bounded evidence.

For the previously inspected Amyris case, the original-accession API facts contain quarterly net income USD 1,533,000 and modern revenue USD 23,194,000; the legacy Revenues tag is absent from the API subset. The actual helper returns zero when given that missing legacy denominator, whereas income/modern revenue is 0.0660946797. This illustrates the code's fallback on observed alternative inputs, not proof that the complete original taxonomy engine made the same mapping decision. safe_sum was inspected statically and loaded; it was not exercised as an empirical benchmark.

## Additional ratios and denominators

The original pilot's four balance-sheet definitions requested 480 comparisons, with 353 direct matches, 20 differences and 107 unavailable. Those results stay separate.

Five new definitions request another 600 comparisons. Exact original-accession USD facts are required. Inventory and balance-sheet values use instant contexts. Income, profit and revenue must share the exact same 60-120 day start/end context. Annual income is never reclassified as a quarter. Broad revenue candidates are Revenues, SalesRevenueNet, RevenueFromContractWithCustomerExcludingAssessedTax and RevenueFromContractWithCustomerIncludingAssessedTax. Different candidate values or starts remain ambiguous; a tag is never chosen because it agrees with the released ratio. Missing/ambiguous facts and zero denominators remain unavailable, not zero.

| Definition | Requested | Direct match | Different | Unavailable | Source zero with nonzero reconstruction |
| --- | --- | --- | --- | --- | --- |
| Quarterly net income / end assets | 120 | 100 | 3 | 17 | 0 |
| (Current assets - inventory) / current liabilities | 120 | 69 | 0 | 51 | 0 |
| Quarterly gross profit / revenue | 120 | 44 | 6 | 70 | 4 |
| Quarterly operating income / revenue | 120 | 54 | 17 | 49 | 13 |
| Quarterly net income / revenue | 120 | 55 | 22 | 43 | 19 |

Thus 370 additional comparisons are computable: 322 matches and 48 differences. The last column counts ratio observations, not unique firms or a population error rate. Most of the twenty-two net-margin differences have released zero but nonzero reconstructed value. This establishes a measurement difference under the specified formula, not that all differences have a single implementation cause. Three ROA differences and other nonzero differences remain unadjudicated; changes in accession selection, contexts, taxonomy, accounting definitions or preprocessing require further work. Code inspection is not a substitute for source-to-output lineage.

## Quarter-specific zeros

quarter_zero_patterns.csv contains twelve feature rates by fiscal quarter for two distinct populations. The full release has 269,097 rows; the deduplicated modeled cohort has 14,657. Net-margin zero rates in the full release are 31.66%, 36.03%, 35.74% and 79.26% in q1-q4 respectively. ROA is zero in 45.97% of full-release q4 rows. However, the modeled cohort includes only 24 q4 observations; its full-release counterpart has 55,435. The annual-file duration filter is a plausible concern deserving reconstruction, not a demonstrated explanation for all zeros or for the model's weak performance. The full-release q4 pattern must not be represented as prevalent q4 exposure in the modeled sample.

## Reproduction

Offline from the package root:

```sh
python3 code/extend_measurement_audit.py analyze
python3 code/verify_measurement_audit.py
```

To re-extract against the exact previously retained SEC cache and pinned financial files:

```sh
python3 code/extend_measurement_audit.py extract --cache local_sec --source-dir local_sources
python3 code/replay_upstream_helpers.py --source local_code/sec_financial_preprocessing_quarterly_extended.py --cache local_sec
```

The helper replay requires pandas and the separately retrieved exact third-party file. The broad source revision and line locators are in upstream_code_manifest.csv. Selected numerical extracts support offline comparisons; the raw-source replay requires the actual original API cache. A future live API snapshot is a different version unless hashes match. No source correction has been selectively applied to the already-inspected predictive cohort.
