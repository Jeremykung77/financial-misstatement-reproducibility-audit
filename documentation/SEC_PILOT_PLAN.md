# Post hoc SEC accession and filing-version audit

This is a descriptive source audit after the benchmark results were inspected. It is not preregistered, population representative, a new predictive experiment, or an untouched evaluation. The Amyris example was inspected before this plan and is reported separately.

Selection, before fetching the remaining companies: all 93 positive evaluation observations (26 firms); 26 distinct firms with no positive label anywhere in the released sampled cohort, ordered by SHA256 of `SEC-PILOT-20261106:` followed by the unpadded decimal CIK, choosing each firm's earliest evaluation observation; and Amyris June 2018 as an explicitly targeted illustration. Nonlinked controls are not verified honest companies. The CSV freezes all 120 observations and 53 firms.

Fetch official SEC companyfacts and submissions JSON, including historical submission files whose stated ranges overlap the relevant periods through one year after the last selected period. Keep request frequency below 10/second. Record errors, source URLs, actual retrieval times and raw SHA256. No proxy, substitute endpoint or access bypass. Downloaded APIs are current aggregations, not historic frozen API snapshots.

For each observation choose the earliest retrieved non-amended 10-Q/10-K with reportDate equal to the economic period end and filingDate no earlier than that date. Preserve accession, primary document URL, filing date and API acceptance timestamp verbatim. This is the earliest matching statutory report in the retrieved history, not certification of the first public financial information. Flag no match and multiple accessions. Do not fall back to a neighboring period or later comparative filing. Legacy API acceptance timestamps require further timezone verification before intraday use; use date-level next-day availability for this pilot.

From the chosen accession retain USD facts for exact period end: Assets, AssetsCurrent, Liabilities, LiabilitiesCurrent, CashAndCashEquivalentsAtCarryingValue; and NetIncomeLoss for 60-120 day duration as a separate earnings diagnostic. Require one distinct value per tag/accession/period/duration. Preserve ambiguities and missing values rather than choosing zero. Standard-taxonomy API coverage is incomplete; a missing fact does not imply absence in the filing.

Reconstruct four explicitly defined balance-sheet ratios: current assets/current liabilities; (current assets-current liabilities)/assets; total liabilities/assets; cash and cash equivalents/assets. Compare with the correspondingly named processed-source ratios at relative tolerance 1e-6 and absolute tolerance 1e-8. A mismatch signals a definition, tag, rounding, context, version or preprocessing issue requiring investigation; it does not by itself prove an error or leakage. Exclude zero denominators and unavailable/ambiguous facts from numeric comparisons and report their counts.

Separately enumerate changes in identical tag/unit/start/end facts across original and later accessions for the selected periods. Such differences may reflect corrections, changes in presentation, discontinued operations or other causes; do not equate every change with fraud or a restatement. For Amyris inspect the original and later primary documents and distinguish quarterly net income from income attributable to common stockholders and total revenues from revenue subcomponents. No models are refit and no benchmark performance result is replaced by this source audit.


## Follow-up amendment after the strict audit

After the six-tag comparison returned 20 cash-only differences, a separate diagnostic considered cash plus one of seven reported investment/combined-cash tags. This was exploratory and did not change the four primary formulas, original accession choice, model input or performance. It found 19 numerical compatibilities. After that diagnostic left one residual, the Sensus original balance sheet was manually inspected and its current/prior-period amounts recorded. The exact prior-year fingerprint is descriptive, with the source implementation mechanism unproven. After 13 exact-date failures, an explicitly separate seven-day candidate search was added; candidate accessions did not enter the strict comparisons. The amended code and outputs preserve the original denominators and the distinction between initial rules and follow-ups.
